# Data dictionary

## data/instances/<task_id>.json
| field | meaning |
|---|---|
| `id`, `family`, `replicate`, `split` | instance identifier, topology family (branch / cycle / bottleneck), replicate index, and the generator's split label |
| `n`, `s`, `t` | number of vertices, source and target |
| `edges[j]` | directed edge (u, v). Edge j is qubit j, which is bit j of the basis index (bit 0 least significant) |
| `costs[j]`, `resources[j]` | integer edge cost and resource |
| `budget` | resource budget R: the lower median of the resources of all simple s–t routes |
| `generator_seed`, `generator_attempt` | provenance from the seeded generator |

`<task_id>.truth.json` is **evaluation only**. It lists every simple s–t route with its `mask`, `cost` and `resource`. The original generator wrote it before training. The tests check it against an independent DFS.

## data/records/fits.csv
There is one row per physical fit, 1470 in total. For each of the 6 configurations: one SHARED_P1 fit, 119 WARM_JOINT, 119 FROZEN_LAYERWISE and 6 RANDOM_JOINT.

| column | meaning |
|---|---|
| `unit` | `<task_id>__<mixer>__s<seed>` |
| `p`, `strategy` | depth; one of SHARED_P1, WARM_JOINT, FROZEN_LAYERWISE, RANDOM_JOINT |
| `status` | BUDGET_EXHAUSTED (the credit cap refused the next call) or CONVERGED (L-BFGS-B success) |
| `loss` | training energy of the winner, <H_C> with H_C normalized to [-1, 1] |
| `energy_report` | the same energy recomputed by the evaluator |
| `p_opt`, `p_feas`, `p_opt_given_feas` | probabilities as fractions, not percent. `p_opt_given_feas` is empty when p_feas = 0 |
| `objective_evaluations`, `gradient_evaluations` | total calls, and calls that also computed the gradient |
| `work_credits`, `work_budget` | credits used (1 per energy-only call, 3 per energy+gradient call) and the cap max(64, 4p) |
| `nominal_layer_work` | p × work_credits |
| `fit_seconds`, `iterations`, `winner_call` | wall time of the fit, L-BFGS-B iterations, and the index of the winning call |
| `active_parameter_count` | trainable angles (2p for WARM and RANDOM, 2 for FROZEN) |
| `earlier_parameter_change` | max absolute change of inherited angles, winner versus initial |
| `ancestor_*` | cumulative cost of all ancestor fits (0 for SHARED_P1 and RANDOM) |
| `cumulative_layer_work`, `cumulative_credits`, `cumulative_fit_seconds`, `cumulative_calls` | ancestors plus own |
| `parent_record`, `parent_sha256`, `winner_sha256` | parent chain and hashes of the original WINNER.json files |
| `has_state`, `complex_state_sha256` | whether the original run saved the complex state, and its hash (states are not shipped) |
| `independent_state_error` | original check against explicit Pauli-string rotation (checkpoints only) |
| `cnot`, `toffoli`, `one_qubit`, `ancillas` | constructive logical-circuit upper bounds for the winner circuit |
| `initial_parameters_sha256` | SHA-256 of `json.dumps(list)` of the initial parameter vector |
| `anchor_present`, `prefix_present` | whether a zero-layer anchor or a fixed prefix was used |

## data/records/angles.json.gz
A JSON object with the following keys:
- `<unit>/p<ppp>/<strategy>`: the winner angles, interleaved [g1, b1, ..., gp, bp];
- `...#initial`: the full initial vector, for WARM and FROZEN at p > 1;
- `...#prefix`: the fixed prefix, for FROZEN.

## data/records/p120_route_distribution.csv
Probability of every feasible route at p = 120 for each unit and strategy, ranked. It is generated by `scripts/replay_states.py`.

## data/records/hamiltonian_fingerprints.json
SHA-256 of the exact float64 arrays H_C and mixer eigenvalues used in training. The tests require bit-identical rebuilds.
